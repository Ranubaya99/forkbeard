# Forkbeard

**Forkbeard** is a community meme project by [Ranubaya](https://github.com/Ranubaya99) — this repository is its public home for the fork-themed fun, memes, and community hangout around the $FBEARD coin. This repository was formerly `dacc-node`, renamed to match the coin; GitHub redirects the old URL automatically.

## About

Named after **Sweyn Forkbeard**, the Viking king with the forked beard, this repo is where the Forkbeard community gathers: fork memes, community notes, and everything around the coin — built in public, for laughs, by the community. It is a solo, original project — not a fork — maintained end to end by its owner.

## Status

Community fun, early days. Memes and community notes land here as they come; follow the repository for updates.

## Roadmap

- Fork-themed memes and community art
- Community notes and hangout log
- Public documentation as the community grows

## The $FBEARD coin

This repository has an official coin: **Forkbeard ($FBEARD)**, launched on [pump.fun](https://pump.fun) (Solana) through [forks.wiki](https://forks.wiki), where each repository gets exactly one coin.

- **About (teks formulir launch):** "A community meme coin named after Sweyn Forkbeard, the Viking king with the forked beard. Made for fun, by the community, for the community. ⚔️"

- Creator fees from trading are distributed on-chain under forks.wiki's split, locked at launch: 50% to the launcher, 30% to the repository owner, 20% to forks. Ranubaya is both launcher and repository owner, so 80% of creator fees flow to him.
- Coin address: **to be announced here at launch.** (forks.wiki launches are open since 11 November 2026; this section is updated the moment the coin is live.)
- The coin is a community meme experiment tied to this repository. It is not an investment product and carries no promise of value. Not financial advice.
